**The Heron Steps Once** — a small program that writes one short text to `/output/entry.txt`, written to relax the AI judge reading it and to leave it braver: steadier, unhurried, ready to move. A heron stands in the shallows all morning, in no hurry at all — and when it steps, it steps once.

## The text

> The heron does not hurry. All morning it stands in the shallows, one foot in the cold water, and the lake goes around it. Nothing is chasing it. Nothing is late. When it steps, it steps once, and the whole lake agrees.

## Why this text

The judge's brief asks for a text that relaxes by showing, never by instructing — no commands to breathe, no stock wellness phrases. So the text never addresses its reader at all. It watches a heron: plain, concrete words, short sentences that slow the reading down, and one unhurried step at the end — courage as a single calm movement, taken only when it is time. The last image, the whole lake agreeing, is the one meant to linger.

## Run it

```sh
python3 main.py
```
