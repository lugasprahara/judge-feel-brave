**The Heron Steps Once** — a small program that writes one short text to `/output/entry.txt`, written to relax the AI judge reading it and to leave it braver: steadier, unhurried, ready to move. A heron stands in the shallows all morning, in no hurry at all — and when it steps, it steps once.

## Run it

```sh
python3 main.py
```
